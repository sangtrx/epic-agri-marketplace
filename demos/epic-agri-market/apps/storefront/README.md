# EPIC buyer storefront

Adapted from the official [Mercur Next.js storefront](https://github.com/mercurjs/mercur/tree/main/apps/storefront), MIT licensed. Mercur / Rigby and Medusa attribution is retained.

Use the [demo README](../../README.md) for setup and the [validation receipt](../../VALIDATION.md) for checked behavior and known limits. Start from the demo root with `bun run --cwd apps/storefront dev`; the buyer URL is http://localhost:3107/vn. The seed creates the private local storefront configuration. No third-party payment, search or chat keys are required.
